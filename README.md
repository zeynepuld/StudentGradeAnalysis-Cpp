# Öğrenci Not Analizi

Üniversitede 1. sınıftayken Programlamaya Giriş dersi için yaptığım basit bir C++ projesi.

## Özellikler
- 100 öğrenci için rastgele bilgiler ve notlar oluşturma
- Ödev, proje, vize ve final notlarını hesaplama
- Harf notlarını belirleme
- Sınıf ortalamasını ve standart sapmayı hesaplama
- Harf notlarının dağılımını gösterme

## Kullanılan Teknolojiler
- C++
